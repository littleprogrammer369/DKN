## 🔴 نکته‌های شما (کاربر)

### ۱. پرچم +۹۸ سمت چپ باید باشه
- الان در همه صفحات (login, register) پرچم +۹۸ **سمت راست** input قرار داره
- باید به **سمت چپ** منتقل بشه
- دلیل: در RTL، پرچم کشور (prefix) باید در ابتدای شماره باشه (مثل شماره‌های بین‌المللی: +۹۸ XXX)
- این فقط یک چیدمان بصریه، نه تغییر دیتا

### ۲. تفکیک فیلدها در روز و شب فرق داره
- **در شب:** فیلدها با border و background جدا از هم مشخص هستن (هر فیلد یه کادر مستقل)
- **در روز:** همه فیلدها به هم چسبیده و یکپارچه به نظر می‌رسن
- باید در روز هم تفکیک visual وجود داشته باشه

### ۳. (کلی) ایموجی‌ها قدیمی شدن
- استفاده از ایموجی‌ها (📧، 🔑، 👤، 🔒) در UI حس می‌ده سایت متعلق به ۲۰۱۵ هست
- پیشنهاد: استفاده از آیکون‌های شکیل‌تر (Lucide, Phosphor, یا custom SVG)
- آیکون‌ها یکدست، مدرن، و scalable هستن

## 🔵 نکته‌های من (AI — اضافه به نکته‌های شما)

### ۴. Tab ها نیاز به active state بهتر دارن
- Tab فعال "رمز عبور" یا "کد تایید" — الان فقط رنگ background عوض می‌شه
- می‌تون با **indicator pill** زیر tab یا **border accent** بهترش کرد
- ترجیحاً **slider animation** بین دو tab

### ۵. دکمه "ارسال کد تایید" نیاز به state های مختلف داره
- حالت **idle**: "ارسال کد تایید"
- حالت **sending**: "در حال ارسال..." + spinner
- حالت **sent**: "کد ارسال شد ✓" + countdown timer (مثلاً ۶۰ ثانیه برای ارسال مجدد)
- حالت **error**: "خطا! دوباره تلاش کنید"

### ۶. فیلد OTP (بعد از ارسال کد)
- الان فقط یه input "کد تایید" می‌بینیم
- بهتره: ۵ یا ۶ input box جداگانه برای هر رقم (کد ۵ رقمی در یک ردیف)
- با **auto-focus** خودکار بین input ها
- با **paste support** (کاربر می‌تونه کد رو paste کنه)

### ۷. لینک "حساب ندارید؟ ثبت‌نام کنید"
- باید حتماً navigate کنه به `/register`
- دکمه نباید disabled باشه

### ۸. فونت input ها
- اعداد تلفن باید با `font-feature-settings: "tnum"` نمایش داده بشن
- یعنی اعداد هم‌عرض (tabular numerals) نه proportional

### ۹. RTL/LTR Mixing
- فیلد تلفن باید **LTR** باشه (چون عدد)
- ولی placeholder فارسی باشه: "۹۱۲۳۴۵۶۷۸۹"
- یا بهتر: همه چی با فونت فارسی ولی فقط عدد LTR

### ۱۰. Bottom link "با استفاده از فناوری..."
- متن کامل نیست، یه جا خالیه یا خیلی کم‌رنگ
- در روز باید خوانا باشه

### ۱۱. Logo در بالا
- لوگو "داده کشت نوین" در یه کادر سبز rounded
- در شب: خوب کار می‌کنه ولی در روز خیلی بزرگه نسبت به بقیه
- باید اندازه متناسب با viewport باشه

### ۱۲. Error handling
- اگه خطا در login رخ بده، باید banner قرمز بالای فرم نمایش داده بشه
- با دکمه "تلاش مجدد"
- و auto-dismiss بعد ۵ ثانیه

### ۱۳. Loading state
- دکمه "ورود" باید موقع click، spinner نشون بده
- text غیرفعال بشه: "در حال ورود..."

### ۱۴. "رمز عبور خود را فراموش کردید؟"
- الان نیست — ولی باید باشه
- لینک کوچک زیر فیلد رمز عبور
