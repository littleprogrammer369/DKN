## 🔵 نکته‌های من (AI)

### ۴. فیلد "نام کاربری" با hint
- الان: `نام کاربری (حداقل ۳ حرف/عدد)` به صورت placeholder
- بهتر: helper text زیر فیلد، نه در placeholder
- چون placeholder موقع تایپ ناپدید می‌شه

### ۵. Password Strength Indicator
- فیلد رمز عبور بدون نشانگر قدرت
- باید: progress bar با ۳ سطح (ضعیف/متوسط/قوی)
- با معیار:
  - ضعیف: < ۸ کاراکتر یا فقط حرف
  - متوسط: ۸+ کاراکتر با حرف و عدد
  - قوی: ۱۲+ کاراکتر با حرف، عدد، و علامت

### ۶. دکمه "نمایش/مخفی کردن رمز"
- الان فقط یک input رمز است
- باید آیکون چشم در سمت چپ (یا راست بسته به RTL) باشد
- با toggle بین `type="password"` و `type="text"`

### ۷. Match validation برای "تکرار رمز"
- الان دو فیلد رمز هست ولی نمی‌فهمم آیا match می‌کنن یا نه
- باید real-time validation: وقتی هر دو پر شدن، match check
- با پیام: "✓ رمزها یکسان هستند" یا "✗ رمزها یکسان نیستند"

### ۸. لینک "حساب دارید؟ وارد شوید"
- باید navigate کنه به `/login`
- استایل: متن با underline یا رنگ primary

### ۹. Privacy/Terms checkbox
- برای ثبت‌نام، باید چک‌باکس "قوانین و حریم خصوصی را می‌پذیرم" باشه
- لینک به صفحه terms
- دکمه ثبت‌نام تا tick نشده، disabled

### ۱۰. Field Order
- الان: نام، نام‌خانوادگی، تلفن، نام‌کاربری، رمز، تکرار رمز
- پیشنهاد: نام، نام‌خانوادگی، نام‌کاربری، تلفن، رمز، تکرار رمز
- یعنی نام‌کاربری قبل از تلفن (چون username اصلی‌تره)

### ۱۱. Hint برای فیلد تلفن
- placeholder: "۹۱۲۳۴۵۶۷۸۹"
- helper text زیر: "شماره موبایل معتبر ایران"

### ۱۲. Auto-formatting
- موقع تایپ تلفن، خودکار space یا dash بگذاره؟ نه — بهتره فقط digit قبول کنه

### ۱۳. Submit on Enter
- اگه همه فیلدها پر، Enter کار کنه (submit form)

### ۱۴. Privacy بابت نام‌کاربری
- موقع ثبت‌نام، real-time check کنه که نام‌کاربری unique باشه
- اگه taken بود: "این نام کاربری قبلاً انتخاب شده"
- با debounce (۵۰۰ms بعد از stop typing)

### ۱۵. Animations
- وقتی فیلد focus می‌شه، border color انیمیشن کنه
- وقتی submit موفق، success animation + redirect

### ۱۶. Success state
- بعد از ثبت‌نام موفق، یه screen کوتاه: "🎉 حساب شما ساخته شد!"
- با auto-redirect به dashboard بعد از ۲ ثانیه

### ۱۷. Email optional
- بعضی سایت‌ها ایمیل هم می‌گیرن. الان نیست. اختیاری به نظرم
