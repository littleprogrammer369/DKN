## 🔵 نکته‌های من (AI)

### ۵. Layout کارت خراب
- الان: "del edit" (چپ) + "1 crop ha 1 - 1" (راست) همگی در یه ردیف
- کاملاً نامرتب و ناخوانا
- بهتر: کارت با ساختار منظم:
  ```
  ┌──────────────────────────────────────┐
  │ 🌾 [نام مزرعه]      [⚙️ 🗑️]          │
  │    گندم • ۱.۱ هکتار                  │
  │    [progress bar health]             │
  └──────────────────────────────────────┘
  ```

### ۶. "1 - 1 هکتار" → "۱.۱ هکتار"
- bug در نمایش — احتمال data درست ولی display اشتباه

### ۷. Quick Actions
- نیاز: "ساخت مزرعه جدید" — یه دکمه اصلی
- یا empty state با CTA

### ۸. Stats Summary
- بالای صفحه: "۳ مزرعه فعال، ۱ نیاز به توجه"
- با badge رنگی

### ۹. Empty State
- اگه مزرعه نداره:
  - "🌱 هنوز مزرعه‌ای نداری"
  - "برای شروع، اولین مزرعه‌ات رو بساز"
  - دکمه بزرگ "ساخت اولین مزرعه"

### ۱۰. Search/Filter
- اگه تعداد زیاد شد:
  - جستجو بر اساس نام
  - فیلتر بر اساس محصول (گندم، ذرت، ...)
  - فیلتر بر اساس وضعیت (فعال/نیاز به توجه)

### ۱۱. Sort
- مرتب‌سازی بر اساس:
  - نام
  - تاریخ ساخت
  - مساحت
  - وضعیت سلامت

### ۱۲. Pull to Refresh
- در mobile، swipe down برای refresh

### ۱۳. Swipe Actions
- در mobile، swipe چپ روی کارت:
  - "ویرایش"
  - "حذف"
  - "جزئیات"

### ۱۴. Tap → Farm Detail
- کلیک روی کارت → `/farms/[id]`

### ۱۵. نمایش در روز
- استفاده از **Glow effect** (همان dashboard)
